A game agent can learn by playing the actual game. It can also learn a model of what the game tends to do, and use that model to practice possible futures.

The second idea is the starting point for a world-model approach to reinforcement learning.

## Learn dynamics, then learn behavior

[DreamerV3](https://arxiv.org/abs/2301.04104) learns a representation of environment dynamics from experience and trains behavior using imagined trajectories. These trajectories unfold in learned latent states rather than requiring every policy-training step to query the real environment.

The world model, policy, and value function have distinct roles. The world model predicts how the represented environment evolves; the policy chooses actions; the value function estimates expected return. The diagram shows their conceptual relationship, not the implementation details of DreamerV3.

This can make collected experience more useful by supporting additional learning in imagination. It does not make interaction data unnecessary: predictions still need grounding in observations from the environment.

## The model can be wrong in useful-looking ways

Consider an illustrative maze with a locked door. A learned model that incorrectly predicts the door opening might assign a high return to repeatedly approaching it. A policy trained only against that prediction could look successful in imagination and fail in the actual maze.

This is not a reported Dreamer result; it is a counterexample that exposes what must be checked. A useful test would compare predicted and observed outcomes specifically near the door, then inspect whether the policy changes when the model receives corrective data.

## What should a world-model evaluation ask?

For a proposed application, three questions help separate concerns:

| Question | Why it matters |
| --- | --- |
| Does it predict action consequences? | A plausible-looking future can still react incorrectly to an action. |
| Does error grow over longer rollouts? | Small local mistakes can change a long-horizon decision. |
| Does the learned behavior work outside the model? | Imagined success is not the final objective. |

These are suggested evaluation questions, not a complete benchmark.

## The LLM connection is a question, not an equivalence

An LLM can predict a tool response or simulate a user. To use those predictions as an RL environment, we still have to define state, actions, rewards, and the relationship to the real task. Generating a plausible continuation is not sufficient evidence that a simulator supports reliable policy improvement.
