An agent is a navigator with a partially wrong map and a too-confident sextant.

Give it tools, a goal, and a loop, and it will chart dotted routes across an environment: search, edit, run, observe, revise. The romance is the voyage. The engineering is the **harbor rules** — permissions, budgets, memory hygiene, and evals that catch when the ship is circling the same island with a new story each time.

## Harbor rules I actually use

1. **Thin tools, sharp feedback** — prefer verbs the environment can verify.
2. **Memory is a liability** until you can audit it.
3. **Stop conditions** are product design, not an afterthought.
4. **Transcripts** are the map legend; without them you only have myths.

Coding agents, research agents, browser agents — same cartography problem at different scales. The Bridgerton stamp is decorative. The dotted path is the work.
